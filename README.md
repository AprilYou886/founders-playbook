# Founders Playbook Skill

一个面向 AI 时代创业者的 Codex / Claude 类 Skill。

它基于 Anthropic 发布的 *The Founder's Playbook* 思路进行蒸馏，把创业过程拆成 `Idea`、`MVP`、`Launch`、`Scale` 四个阶段，并为每个阶段提供结构化诊断框架、追问方式、退出标准和行动模板。

这个 skill 的目标不是安慰创始人，而是帮助创始人更早看见真实问题：想法是否值得做、MVP 是否被功能欲望拖垮、发布后是否真的具备牵引力、规模化前系统是否已经足够稳固。

## 适合谁使用

- 正在验证创业想法的人
- 正在构建 MVP 的独立开发者或小团队
- 已经上线产品、但不确定是否有 PMF 的创始人
- 正在从早期牵引力走向规模化的 AI-native 团队
- 想把创业判断流程沉淀进 AI 助手的人

## 它能做什么

这个 skill 会先判断你当前所处的创业阶段，然后切换到对应框架：

| 阶段 | 核心问题 | 主要输出 |
| --- | --- | --- |
| Idea | 这个问题值不值得解决？ | 问题假设打磨、反证压力测试、客户访谈设计、轻量原型边界 |
| MVP | 我们该先做什么？怎么做？ | 架构预设、范围约束、安全审查、衡量框架、PMF 退出诊断 |
| Launch | 这是真实牵引力，还是早期热情？ | 技术健康度、运营去瓶颈化、安全合规、产品管理系统审计 |
| Scale | 怎么在不失控的前提下快速增长？ | 授权运营、技术运营规模化、GTM 职能、护城河成熟度诊断 |

## 触发方式

当你在 Codex / Claude 等支持 skill 的环境中安装后，可以用类似下面的话触发：

```text
我有一个产品想法，帮我判断值不值得做
```

```text
我在做 MVP，但功能越来越多，帮我收一下范围
```

```text
产品上线了，有一些用户但留不住，帮我诊断一下
```

```text
我准备扩张团队和融资，帮我看看是否到了 Scale 阶段
```

skill 会根据上下文自动判断你处于 `Idea / MVP / Launch / Scale` 中的哪个阶段，并用对应的诊断流程继续追问。

## 安装方式

### Codex

将本仓库克隆到你的 Codex skills 目录，或复制 `SKILL.md` 到一个新的 skill 文件夹中：

```bash
mkdir -p ~/.codex/skills/founders-playbook
cp SKILL.md ~/.codex/skills/founders-playbook/SKILL.md
```

重启 Codex 后即可使用。

### Claude / 其他兼容环境

如果你的环境支持 `SKILL.md` 格式，可以将本仓库中的 `SKILL.md` 放入对应的 skills 目录。

目录结构通常类似：

```text
founders-playbook/
  SKILL.md
```

## 设计原则

这个 skill 遵循几个原则：

- **先诊断阶段，再给建议**：不同阶段的问题不能混用同一套答案。
- **反证优先**：尤其在 Idea 阶段，优先寻找为什么这个想法会失败。
- **每次只推进一步**：避免一次性输出大量泛泛建议，让用户无法行动。
- **退出标准明确**：每个阶段都应该知道什么条件下可以进入下一阶段。
- **对创始人诚实**：不提供安慰剂，不把早期热情误判成真实牵引力。
